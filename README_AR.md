# مذيع السنبلاوين — مشروع Android

هذا مشروع Android Studio يحوّل واجهة التطبيق إلى تطبيق أندرويد يفتح محلياً داخل WebView.

## ما يعمل في هذه النسخة التجريبية
- واجهة عربية متوافقة مع شاشة الهاتف.
- تسجيل الشكاوى التجريبية على الجهاز نفسه (Local Storage).
- رقم متابعة تجريبي وإدارة محلية للحالات.

## غير مكتمل بعد
- لا يوجد سيرفر أو استقبال شكاوى من أجهزة أخرى.
- لا يوجد تسجيل دخول إداري آمن.
- لا توجد حماية بيانات/مزامنة مركزية. لا تستخدموا هذه النسخة للبيانات الحقيقية.
- لا يوجد APK مبني في هذا الملف المضغوط؛ هذا مصدر المشروع.

## بناء APK عبر GitHub Actions
1. أنشئ مستودع GitHub جديداً وارفع محتويات هذا المجلد إلى فرع `main`.
2. من تبويب Actions شغّل `Build Android APK` (أو انتظر التشغيل عند push).
3. افتح نتيجة التشغيل الناجح، ثم نزّل Artifact باسم `Moze3-Sennbelawen-debug-apk`.
4. فك ضغط الـ Artifact، ثم ثبّت `app-debug.apk` على هاتف Android. قد يطلب Android السماح بالتثبيت من المصدر الذي نزّلت منه.

أو افتح المجلد في Android Studio، انتظر Gradle Sync، ثم Build > Build APK(s).
